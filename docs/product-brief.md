# Axis product brief

Axis is a Windows-first artist-oriented application for producing variable TTF fonts from compatible font masters.

## First release

- Weight (`wght`) is active by default.
- Weight and upright/slanted metadata are detected and populated automatically.
- Files and folders can be added repeatedly.
- Incompatible rows expose `Trim to shortest` and `Remove file` actions.
- Start is enabled only when all source rows pass compatibility validation.
- Users can add future axes through a plus control and choose common names or type a custom name.
- Export uses a standard Save dialog and opens the generated TTF in Windows Font Preview.

## Visual language

The reference artwork is retained in `reference/`. The interface uses a dark, black-overlay treatment with approximately 80% opacity and a soft 100px blur, rounded panels, restrained color, and strong typography.
